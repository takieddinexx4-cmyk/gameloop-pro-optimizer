# 🎮 GAMELOOP PRO OPTIMIZER

> **الإصدار:** `1.0.0` | **النظام:** `Windows` | **التقنية:** `Python 3.11 + PySide6` | **اللغات:** `العربية (RTL) / English (LTR)` | **الرخصة:** `MIT`

**GAMELOOP PRO OPTIMIZER** هو برنامج سطح مكتب احترافي لنظام Windows مصمّم لتشخيص ومعالجة مشاكل **GameLoop / PUBG Mobile** (اللاج، هبوط الإطارات، التقطيع، التجميد، زمن الاستجابة، الأعطال، استهلاك الموارد، وأخطاء ADB) بأسلوب علمي شفاف، آمن تماماً، وقابل للتراجع الكامل.

*A diagnostic-driven, safety-first Windows desktop suite built with **Python 3.11 + PySide6** to diagnose and mitigate **GameLoop / PUBG Mobile** stability, stuttering, crash, resource, and ADB issues — with zero telemetry and full SHA-256 verified rollback.*

## ✨ أبرز المميزات (Key Highlights)

- **أمان كامل للنظام:** لا يقوم البرنامج إطلاقاً بتعطيل Windows Defender أو الجدار الناري أو Windows Update، ولا يعبث بإعدادات الإقلاع (`bcdedit`).
- **سلسلة تعديل موثقة وقابلة للتراجع:** كل تحسين يمر بخطوات إلزامية: قراءة الحالة الحالية ← معاينة التغيير ← موافقة المستخدم ← إنشاء نسخة احتياطية موثقة ببصمة `SHA-256` ← التطبيق ← التحقق ← إمكانية التراجع الكامل أو الفردي.
- **صدق هندسي بلا أرقام وهمية:** أي مستشعر غير متاح (مثل الحرارة بدون LibreHardwareMonitor/OpenHardwareMonitor أو معدل الإطارات بدون RTSS) يظهر بوضوح كـ **«غير متاح / Unavailable»** مع ذكر السبب، دون أي وعود زائفة بزيادة الإطارات.
- **حماية صارمة لبيانات اللعبة والمستخدم:** منظّف **Cleaner PRO** يعمل بمعاينة إلزامية قبل التنظيف، ويحظر تماماً المساس بملفات اللعبة والإعدادات والمستخدم، وينقل الملفات المؤقتة القديمة إلى **سلة المحذوفات (Recycle Bin)** فقط.
- **واجهة داكنة ثنائية اللغة:** واجهة PySide6 حديثة تدعم التبديل الفوري بين العربية (مع اتجاه RTL حقيقي) والإنجليزية (LTR).
- **بلا تيليمتري وبلا تنزيلات صامتة:** جميع أوامر النظام تُنفَّذ بأمان (`shell=False`)، ولا توجد أي عمليات تتبع أو تنزيلات تلقائية في الخلفية.

## 🛠️ الشرح التفصيلي للخدمات

### 1. تحليل الجهاز (PC Analysis)
- يقرأ المواصفات الفعلية للجهاز: المعالج (CPU وعدد الأنوية الفيزيائية)، الذاكرة العشوائية (RAM)، كرت الشاشة وحجم VRAM (مع بديل قراءة 64-bit لتجاوز قيود WMI التقليدية)، أقراص التخزين، دقة الشاشة ومعدل التحديث (Hz)، وإصدار Windows.
- يكشف مسار تثبيت GameLoop وإصداره تلقائياً.
- يعرض حالة المستشعرات بصدق تام (`Unavailable`) عند عدم توفر مزوّد قراءة للحرارة أو GPU.

### 2. التحسين الذكي (Smart Optimization)
يدعم ثلاثة أوضاع: **آمن (Safe)**، **متقدم (Advanced)**، و**مخصّص (Pro Custom)**، ويتيح معاينة القيمة الحالية والمقترحة قبل التطبيق، مع نسخة احتياطية وتراجع فردي لكل تعديل:

| التعديل | المعرّف البرمجي | صلاحيات Admin | النسخ الاحتياطي والتراجع |
| :--- | :--- | :---: | :---: |
| تفعيل وضع الألعاب في Windows (Game Mode) | `windows_game_mode` | لا | نعم |
| إيقاف التسجيل الخلفي (Game DVR) | `disable_game_dvr` | لا | نعم |
| خطة الطاقة عالية الأداء (High Performance) | `power_plan_high_perf` | لا | نعم |
| جدولة GPU العتادية (HAGS) | `windows_hags` | نعم | نعم |
| تفضيل كرت الشاشة القوي لمحاكي GameLoop | `gameloop_gpu_preference` | لا | نعم |
| تحسينات ملء الشاشة وDPI لـ GameLoop | `gameloop_fullscreen_dpi` | لا | نعم |

> عند تشغيل البرنامج كمستخدم عادي (بدون صلاحيات مسؤول)، تعمل جميع التعديلات غير المتطلبة لـ Admin بشكل طبيعي، بينما تنتقل تعديلات `HKLM` مثل HAGS بأمان إلى حالة «غير متاح» دون أي خطأ.

### 3. مركز الأعطال واللاج (Crash & Lag Center)
- فحص تلقائي لتوقيعات الأخطاء في سجلات GameLoop (`gameloop_logs`).
- قراءة وتحليل أحداث النظام والتطبيقات من **Windows Event Log**.
- فحص حالة جسر **ADB** ومراقبة ضغط المعالج والذاكرة والقرص.
- توفير أزرار إصلاح آمنة مباشرة (`Fix Now`) عند توفر حل برمجي آمن، أو إرشادات يدوية واضحة للحالات التي تتطلب تدخلاً يدوياً.
- تصدير تقرير تشخيصي كامل بصيغة `JSON`.

### 4. ملفات PUBG الذكية (PUBG Profiles)
يولّد البرنامج 5 أنماط أساسية بالإضافة إلى نمط **Custom**، ويضبط سقف الدقة والإطارات والأنوية والذاكرة **تلقائياً** بما لا يتجاوز قدرات جهازك المكتشفة ومعدل تحديث شاشتك (مع تحذيرات واضحة عند تطبيق أي سقف)، كما يدعم الاستيراد والتصدير والنسخ الاحتياطي:

| النمط (Profile) | الفئة | المحرك | الدقة الأساسية | الإطارات المستهدفة | الجرافيك | تنعيم الحواف | الأنوية / RAM |
| :--- | :--- | :--- | :--- | :---: | :--- | :--- | :---: |
| **Low-End Stability** | للأجهزة الضعيفة | Auto | `1280×720` | 60 FPS | Smooth | Close | 2 / 2048 MB |
| **Balanced** | متوازن | Auto | `1600×900` | 60 FPS | Smooth | Balanced | 4 / 4096 MB |
| **High Performance** | أداء عالٍ | DirectX+ | `1920×1080` | 90 FPS | Smooth | Close | 4 / 4096 MB |
| **Competitive** | تنافسي | DirectX+ | `1920×1080` | 120 FPS | Smooth | Close | 4 / 4096 MB |
| **High Graphics** | جرافيك عالٍ | DirectX+ | `1920×1080` | 60 FPS | HD | Balanced | 4 / 6144 MB |

### 5. مركز GameLoop وجسر ADB (GameLoop Center)
- اكتشاف ديناميكي لمسار GameLoop ومنافذ الاتصال، مع إمكانية تعيين مسار مخصّص من الإعدادات.
- تشغيل، إيقاف، وإعادة تشغيل عمليات GameLoop بأمان.
- أزرار وصول سريع لمجلد التثبيت، مجلد الإعدادات، مجلد السجلات، ومجلد الواجهة (UI).
- تحكم كامل بجسر **ADB**: فحص الحالة، الاتصال، قطع الاتصال، وإصلاح مشاكل الاتصال.

### 6. أدوات الألعاب والإدخال وإدارة العمليات (Gaming Tools & Process Manager)
- **ضبط العمليات وكرت الشاشة:** تقييم وضبط أولوية العمليات (Priority/Affinity) وتفضيل GPU، مع قائمة حماية صارمة تمنع إنهاء أو تعديل عمليات النظام الحرجة (مثل `lsass.exe` و`csrss.exe` و`dwm.exe` و`explorer.exe` و`msmpeng.exe`).
- **الماوس وزمن الإدخال:** فحص إعدادات الماوس وإمكانية إيقاف أو إعادة تفعيل تسريع الماوس (Enhanced Pointer Precision) مع حفظ نسخة احتياطية مسبقاً.
- **الأدوات الخارجية الاختيارية:** يعرض البرنامج روابط رسمية فقط (دون تنزيل تلقائي) لأدوات مساعدة اختيارية، مع أداة مدمجة للتحقق من التوقيع الرقمي (`WinVerifyTrust`) وبصمة `SHA-256` لأي ملف تقوم بتنزيله يدوياً:
  - [Process Lasso](https://bitsum.com/) — لجدولة العمليات (يعمل البرنامج بالكامل بدونها).
  - [RivaTuner Statistics Server (RTSS)](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) — لتثبيت الإطارات وتوفير قراءة FPS موثوقة عبر الذاكرة المشتركة.
  - [X-Mouse Button Control](https://www.highrez.co.uk/downloads/XMouseButtonControl.htm) — لتخصيص أزرار الماوس.

### 7. المراقبة الحية (Live Monitor)
- مراقبة منخفضة الاستهلاك في الخلفية بفاصل تحديث قابل للتخصيص من الإعدادات.
- رسوم بيانية مرسومة عبر `QPainter` لعرض الأداء خلال **60 ثانية** و**5 دقائق**.
- دعم قراءة الإطارات (FPS) بنمط **القراءة فقط** عبر `RTSSSharedMemoryV2` عند تشغيل RivaTuner.

### 8. المنظّف الاحترافي (Cleaner PRO)
- يفرض **المعاينة الإلزامية** قبل أي عملية تنظيف.
- يقتصر الفحص على قائمة سماح صارمة لامتدادات الملفات المؤقتة والسجلات داخل مجلدات GameLoop المعتمدة فقط: `.log`، `.tmp`، `.temp`، `.dmp`، `.old`، `.trace`، `.etl`، `.cache` (مع إمكانية تحديد الحد الأدنى لعمر السجلات بالأيام من الإعدادات).
- يحظر تماماً المساس بملفات اللعبة والإعدادات والملفات الشخصية (مثل `.sav`، `.ini`، `.cfg`، `.conf`، `.json`، `.xml`، `.pak`، `.obb`، `.apk`، `.exe`، `.dll`، وملفات `UserCustom`/`Active.sav` ومجلدات النظام والمستخدم).
- ينقل الملفات المحددة إلى **سلة المحذوفات** فقط عبر `send2trash` لضمان إمكانية الاسترجاع.

### 9. النسخ الاحتياطي والاستعادة (Backup & Restore)
- إنشاء لقطات احتياطية كاملة لإعدادات GameLoop وRegistry قبل أي تعديل.
- التحقق من سلامة كل نسخة احتياطية باستخدام بصمة **`SHA-256`**.
- دعم الاستعادة الكاملة للقطة أو الاستعادة الفردية لعنصر محدد.

### 10. فحص الاعتماديات والتحديثات (Dependencies & Updates)
- فحص غير متطفل (بدون تثبيت صامت) لحزم التشغيل الأساسية مع روابط رسمية من Microsoft:
  - [Microsoft Visual C++ 2015–2022 Redistributable (x64 & x86)](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)
  - [DirectX End-User Runtime](https://www.microsoft.com/en-us/download/details.aspx?id=35)
  - [.NET Framework](https://dotnet.microsoft.com/en-us/download/dotnet-framework)
  - فحص حالة المحاكاة الافتراضية (**Virtualization**) للقراءة فقط.
- فحص اختياري لتحديثات **GitHub Releases** مع التحقق من ملف `.sha256` الرسمي قبل الاعتماد.

## 🔒 مبادئ الأمان والخصوصية

1. **لا مساس بأمان Windows:** لا يتم تعطيل Defender أو Firewall أو Windows Update أو تعديل `bcdedit`.
2. **صلاحيات محدودة وشفافة:** يعمل البرنامج في الوضع الآمن كمستخدم عادي، ويوضح بصرياً أي ميزة تتطلب صلاحيات المسؤول.
3. **تنفيذ آمن للأوامر:** جميع استدعاءات العمليات تستخدم قوائم معاملات آمنة بدون `shell=True`.
4. **خصوصية تامة:** لا توجد تحليلات استخدام (Telemetry) أو اتصالات خلفية غير مصرح بها (فحص التحديثات وTCP Ping اختياريان بالكامل).

## 🚀 التثبيت والتشغيل

### الطريقة 1: التشغيل المباشر عبر الإصدارات الجاهزة (موصى بها للمستخدمين)
1. حمّل ملف `GAMELOOP PRO OPTIMIZER.exe` وملف التحقق `GAMELOOP PRO OPTIMIZER.exe.sha256` من صفحة **Releases** في المستودع.
2. تحقّق من سلامة الملف عبر PowerShell:
   ```powershell
   Get-FileHash ".\GAMELOOP PRO OPTIMIZER.exe" -Algorithm SHA256
   ```
3. طابق الناتج مع محتوى ملف `.sha256` ثم شغّل البرنامج.

### الطريقة 2: التشغيل من الكود المصدري (للمطورين)
**المتطلبات:** نظام Windows + **Python 3.11**

```bash
git clone [https://github.com/](https://github.com/)<YOUR_GITHUB_USERNAME>/gameloop-pro-optimizer.git
cd gameloop-pro-optimizer
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python src/main.py
```

شغّل سكربت البناء المرفق لإنشاء البيئة الافتراضية، تشغيل الاختبارات، توليد الأيقونة، وبناء الملف التنفيذي مع بصمة SHA-256:

```bat
build.bat
```

**المخرجات:**
- `dist\GAMELOOP PRO OPTIMIZER.exe`
- `dist\GAMELOOP PRO OPTIMIZER.exe.sha256`

### البناء التلقائي عبر GitHub Actions
يحتوي المستودع على مسار عمل جاهز في `.github/workflows/build.yml` يعمل على `windows-latest` ويقوم تلقائياً بما يلي:
1. إعداد Python 3.11 وتثبيت الاعتماديات المثبّتة في `requirements.txt`.

4. بناء ملف تنفيذي واحد (`--onefile --windowed`) عبر PyInstaller مع الأيقونة ومعلومات الإصدار (`version_info.txt`).
5. حساب بصمة `.sha256` ورفع الملفين كـ Artifact، وإنشاء **GitHub Release** تلقائياً عند دفع وسم إصدار مثل `v1.0.0`.

> لتفعيل فحص التحديثات داخل التطبيق لمستودعك الخاص، حدّث `DEFAULT_GITHUB_OWNER` و`DEFAULT_GITHUB_REPO` في `src/gameloop_optimizer/app_core/constants.py` أو من صفحة **Settings** داخل البرنامج.

تغطي الاختبارات الحالات الحرجة باستخدام Mocks معزولة: غياب GameLoop، المسارات غير القياسية، انقطاع ADB، غياب المستشعرات، التشغيل بدون صلاحيات Admin، التراجع الكامل، سلامة `SHA-256`، وحماية `Cleaner PRO`.

### ملاحظة مهمة حول الاختبار على جهاز حقيقي
الميزات المتفاعلة مباشرة مع `WMI` و`Windows Registry` و`Windows Event Log` و`adb.exe` و`RTSSSharedMemoryV2` وGameLoop الفعلي لم تُختبر بعد على جهاز Windows حقيقي أثناء التطوير؛ يُنصح بتنفيذ قائمة التحقق اليدوية التالية عند أول تشغيل:

1. شغّل `GAMELOOP PRO OPTIMIZER.exe` كمستخدم عادي (بدون Admin) وتأكد من ظهور شارة **مستخدم عادي (وضع آمن)** وسقوط تعديل `HKLM` (مثل HAGS) بأمان إلى حالة «غير متاح».
2. افتح **PC Analysis** واضغط تحليل، وتأكد من مطابقة CPU/RAM/GPU/VRAM/دقة الشاشة/التردد لبيانات جهازك، وأن الحرارة تظهر «غير متاح» عند عدم تشغيل LibreHardwareMonitor.
3. افتح **GameLoop Center** وتأكد من كشف مسار GameLoop (أو تعيين مسار مخصّص في **Settings**)، وجرّب فحص وإصلاح ADB مع تشغيل المحاكي.
4. افتح **Smart Optimization** (وضع Safe)، طبّق **Windows Game Mode** بعد مراجعة نافذة التأكيد، ثم جرّب **Rollback Selected** وتأكد من عودة القيمة الأصلية.
5. افتح **Cleaner PRO**، اضغط معاينة وتأكد من عدم ظهور أي ملف `.sav` أو `.ini`، وجرّب نقل ملف سجل قديم وتأكد من وجوده في سلة المحذوفات.
6. بدّل اللغة بين العربية والإنجليزية من الشريط العلوي وتأكد من انعكاس اتجاه الواجهة بالكامل (`RTL` / `LTR`).
7. افتح **Live Monitor** لمدة دقيقة وتحقق من انخفاض استهلاك CPU للبرنامج نفسه ومن عمل نافذتي 60 ثانية و5 دقائق، وتحقق من قراءة RTSS فقط عند تشغيل RivaTuner.
